4. Upgrading IOS via TFTP

TFTP runs on UDP port 69. The PC running the TFTP Server (such as Tftpd64) must be in the same Subnet as the switch, the IOS file must sit in the server's Root folder, and the PC's Firewall must be off or allow the transfer.

1) Preparation and backup

show version
show flash:
ping 192.168.1.100

copy running-config tftp:
copy flash:c2960-lanbasek9-mz.150-2.SE11.bin tftp:

In show version check the current version, and in show flash: check the free space; there must be enough room for the new image. If there isn't, delete the old image with delete flash:file-name (after taking a backup).

2) Copy the new image

copy tftp: flash:
Address or name of remote host []? 192.168.1.100
Source filename []? c2960-lanbasek9-mz.152-7.E9.bin
Destination filename [c2960-lanbasek9-mz.152-7.E9.bin]?   (Enter)

verify /md5 flash:c2960-lanbasek9-mz.152-7.E9.bin

If the file is a .tar, use the following command instead of copy; it extracts and installs the image by itself:

archive download-sw /overwrite tftp://192.168.1.100/c2960-lanbasek9-tar.152-7.E9.tar

3) Select the boot image and reload

configure terminal
boot system flash:c2960-lanbasek9-mz.152-7.E9.bin
end
write memory
reload

4) Verification

show version
show boot
Don't cut the power or the cable during the copy. Before the Reload, always compare the file's MD5 with the value on Cisco's site, and keep the previous image until you're sure the new one works.
Memory aid: backup → copy with copy tftp: flash: → verify /md5 → boot system → reload

5. Resetting the Switch (Erasing the Config)

To return the switch to factory state, both the Startup-Config and the VLAN data must be erased.

enable
write erase
delete flash:vlan.dat
reload

Commands that erase the config (all three are equivalent)

write erase
erase startup-config
erase nvram:

Erasing the nvram filesystem will remove all configuration files! Continue? [confirm]

All three erase only the Startup-Config. VLAN data is stored separately in vlan.dat and is removed with delete flash:vlan.dat. On some platforms (such as routers), erase /all nvram: erases all NVRAM files.

During the process:

  • delete asks for confirmation twice (the file name and the delete confirmation).
  • During reload, if it asks “System configuration has been modified. Save?”, answer no; otherwise the current config is saved again.
  • Then confirm the Reload.

Verification after boot

show startup-config
show vlan brief
show running-config

You should see the message startup-config is not present, and only the default VLANs (1 and 1002–1005) should appear.

Erasing the config does not change the Running-Config right away; all settings stay active until the Reload. Don't run write memory between write erase and reload.
Memory aid: write erase → delete flash:vlan.dat → reload (answer no to Save)
Part 2 — Switching

6. VLAN, Trunk and Inter-VLAN

VLANs split the network at Layer 2 into separate Broadcast Domains, and each VLAN usually has its own Subnet.

vlan 10
 name Sales
interface fa0/2
 switchport mode access
 switchport access vlan 10

interface g0/1
 switchport trunk encapsulation dot1q
 switchport mode trunk
 switchport trunk native vlan 99
 switchport trunk allowed vlan 10,20,99

The switchport trunk encapsulation dot1q command is only needed on switches that also support ISL. In 802.1Q, Native VLAN traffic is sent untagged.

Router-on-a-Stick

interface g0/0
 no shutdown
interface g0/0.10
 encapsulation dot1Q 10
 ip address 192.168.10.1 255.255.255.0
interface g0/0.99
 encapsulation dot1Q 99 native

Layer 3 switch (SVI)

ip routing
interface vlan 10
 ip address 192.168.10.1 255.255.255.0
 no shutdown

Verification

show vlan brief
show interfaces trunk
show interfaces g0/1 switchport
The Native VLAN must match on both ends of a Trunk; otherwise a mismatch warning appears and traffic ends up in the wrong VLAN.

7. STP — Election Rules

Root Bridge election

The lowest Bridge ID wins.

Bridge ID = Priority + MAC Address

So Priority is checked first and, if it's equal, the MAC.

Root Port election

  1. Lowest Root Path Cost
  2. Lowest Sender Bridge ID
  3. Lowest Sender Port ID

Designated Port election

  1. Lowest Root Path Cost
  2. Lowest Bridge ID
  3. Lowest Port ID
Memory aid: Root Bridge → Root Port → Designated Port → Blocked Port

For the Root Bridge: Priority ↓ → MAC ↓ (lower wins)

The default STP Priority is usually 32768.

8. STP — Extras (RSTP, PortFast, BPDU Guard)

The real Bridge ID = Priority + VLAN ID (Extended System ID) + MAC; that's why the default Priority of VLAN 1 shows as 32769. Priority can only be a multiple of 4096.

10. PoE (Power over Ethernet)

PoE delivers power to devices such as IP phones, Access Points and cameras over the same network cable. The switch is the PSE (power source) and the device is the PD (powered device). Only PoE models of the switch support this.

StandardNamePSE output power
802.3afPoE15.4 W
802.3atPoE+30 W
802.3btPoE++60 W / 90 W
Cisco UPOEProprietary60 W

Configuration

interface fa0/5
 power inline auto
 power inline auto max 15400
 power inline static max 15400
 power inline never
  • auto: the default; the switch detects the PD and supplies power.
  • static: reserves power from the Budget for that port.
  • never: PoE is off on the port.
  • max: the port's power ceiling in milliwatts.

Verification

show power inline
show power inline fa0/5
show power inline detail

The output of show power inline shows Admin (auto/off), Oper (on/off/faulty/power-deny), power drawn, device type and Class. The top of the table also shows the Available, Used and Remaining figures for the whole switch's Budget.

If Oper is power-deny, the switch's Budget isn't enough. If it's faulty, the cable or the device itself has a problem.
PoE stages: Detection → Classification → Power-Up. The exact power draw is usually negotiated between the switch and the PD using CDP or LLDP-MED.
Part 3 — Routing

11. Static Route

A Static Route means defining the path manually on the router.

Via Next-Hop

ip route 192.168.2.0 255.255.255.0 10.0.0.2

Via Interface

ip route 192.168.2.0 255.255.255.0 g0/1

Default Route

ip route 0.0.0.0 0.0.0.0 10.0.0.2

This means any destination without a specific Route is sent to the Next-Hop.

Verification

show ip route
show running-config | include ip route

Removal

no ip route 192.168.2.0 255.255.255.0 10.0.0.2

13. OSPF at CCNA Level

OSPF is a Dynamic Routing Protocol.

Setup

router ospf 1
 router-id 1.1.1.1
 network 192.168.1.0 0.0.0.255 area 0
 network 10.0.0.0 0.0.0.3 area 0

The number 1 is the Process ID and is not necessarily the Router ID.

Second router

router ospf 1
 router-id 2.2.2.2
 network 192.168.2.0 0.0.0.255 area 0
 network 10.0.0.0 0.0.0.3 area 0

Verification

show ip ospf neighbor
show ip route ospf
show ip ospf
show ip protocols

A healthy Neighbor is normally in the FULL state. OSPF routes are shown with the letter O.

OSPF Message Types

No.MessageUsage
1HelloDiscover and maintain Neighbors
2DBDLSDB summary
3LSRRequest the needed LSAs
4LSUSend LSAs
5LSAckAcknowledge received LSAs
Memory aid: Hello → DBD → LSR → LSU → LSAck

Router ID selection

  1. Manual Router-ID with router-id x.x.x.x
  2. Highest IP on a Loopback
  3. If there's no Loopback, the highest IP on an active Interface

14. OSPF — Extras (DR/BDR, Cost, Passive)

Neighbor requirements

  • Same Area, Subnet/Mask, Hello/Dead Timers and MTU
  • Unique Router ID and matching Authentication

The default Timers on Broadcast and Point-to-Point networks are Hello 10 and Dead 40 seconds.

DR / BDR

On a Multi-Access network such as Ethernet, one DR and one BDR are elected. The criteria are the highest Priority (default 1), then the highest Router ID. The election is Non-Preemptive, and Priority = 0 never becomes DR. DROthers stay in the 2-Way state with each other, which is normal.

Addresses: 224.0.0.5 for all OSPF routers and 224.0.0.6 for DR/BDR.

Cost and useful commands

Cost = Reference Bandwidth ÷ Bandwidth (the default is 100 Mbps, so Fa and Gig both get Cost 1).

router ospf 1
 auto-cost reference-bandwidth 1000
 passive-interface g0/0

interface g0/1
 ip ospf priority 100
 ip ospf network point-to-point
 ip ospf cost 10
Neighbor state memory aid: Down → Init → 2-Way → ExStart → Exchange → Loading → Full

15. Default Route and Advertising it in OSPF

ip route 0.0.0.0 0.0.0.0 10.0.0.2

16. EIGRP at CCNA Level

EIGRP = Enhanced Interior Gateway Routing Protocol

  • Advanced Distance Vector
  • It uses DUAL.
  • The main Metric is based on Bandwidth and Delay.
  • Internal AD = 90
  • External AD = 170
  • Route Code = D

Setup

router eigrp 100
 network 192.168.1.0 0.0.0.255
 network 10.0.0.0 0.0.0.3

The number 100 is the AS Number, and EIGRP routers must have the same AS to become Neighbors.

Verification

show ip eigrp neighbors
show ip route eigrp
show ip eigrp topology

Key concepts

  • Successor: the best path
  • Feasible Successor: a loop-free backup path
  • Feasible Distance (FD): the best calculated Metric
  • Reported Distance (RD): the Metric advertised by the Neighbor
DUAL: Best Path → Successor | Backup Path → Feasible Successor

Message Types

MessageUsage
HelloDiscover and maintain Neighbors
UpdateSend Route information
QueryAsk Neighbors about a route
ReplyReply to a Query
ACKAcknowledge reliable messages
Memory aid: Hello → Update → Query → Reply → ACK

Default Route in EIGRP

ip route 0.0.0.0 0.0.0.0 10.0.0.2

router eigrp 100
 redistribute static

no auto-summary

router eigrp 100
 no auto-summary

This command reflects old EIGRP behavior. In newer IOS versions Auto-Summarization is normally off by default, so there's no need to add it to every config.

18. ACL at CCNA Level

ACL = Access Control List

Used to Permit/Deny traffic.

Standard ACL

Checks the Source IP only.

access-list 10 deny host 192.168.10.10
access-list 10 permit any

Extended ACL

Checks Source IP + Destination IP + Protocol + Port.

Example: block HTTP from the VLAN 10 network to server 192.168.100.20:

access-list 100 deny tcp 192.168.10.0 0.0.0.255 host 192.168.100.20 eq 80
access-list 100 permit ip any any

Applying the ACL to an Interface

interface g0/0
 ip access-group 100 in

in: traffic entering the Interface.

out: traffic leaving the Interface.

Named ACL

ip access-list extended BLOCK-HTTP
 deny tcp 192.168.10.0 0.0.0.255 host 192.168.100.20 eq 80
 permit ip any any
 exit

interface g0/0
 ip access-group BLOCK-HTTP in

Important points

  • An ACL is checked from top to bottom.
  • The first Rule that matches is applied.
  • There's an Implicit Deny at the end of every ACL.
  • Standard ACL → Source IP only
  • Extended ACL → Source + Destination + Protocol + Port
CCNA memory aid: Standard near the destination, Extended near the source.

19. NAT at CCNA Level

NAT = Network Address Translation

Translating Private IPs to Public and vice versa.

NAT types

TypeDescription
Static NATOne Private ↔ one Public
Dynamic NATPrivate → a Pool of Public IPs
PAT / NAT OverloadMany Private → one Public using Port Numbers

Static NAT

interface g0/0
 ip address 192.168.1.1 255.255.255.0
 ip nat inside
 no shutdown

interface g0/1
 ip address 203.0.113.1 255.255.255.0
 ip nat outside
 no shutdown

ip nat inside source static 192.168.1.10 203.0.113.10

Dynamic NAT

access-list 1 permit 192.168.1.0 0.0.0.255

ip nat pool PUBLIC 203.0.113.10 203.0.113.20 netmask 255.255.255.0

ip nat inside source list 1 pool PUBLIC

interface g0/0

interface g0/1
 ip nat outside

PAT

access-list 1 permit 192.168.1.0 0.0.0.255

interface g0/0

interface g0/1

ip nat inside source list 1 interface g0/1 overload

overload = PAT

show ip nat statistics

Part 5 — Redundancy and WAN

20. FHRP — HSRP

HSRP creates a virtual Gateway between two routers so clients aren't cut off when one fails. The router with the highest Priority (default 100) becomes Active and the other becomes Standby.

interface g0/0
 ip address 192.168.1.2 255.255.255.0
 standby 1 ip 192.168.1.1
 standby 1 priority 110
 standby 1 preempt
show standby brief

Clients' Default Gateway must be the virtual IP (192.168.1.1). HSRP is Cisco-proprietary; VRRP is the open standard, and GLBP also does Load Balancing on top of Redundancy.

21. GRE Tunnel at CCNA Level

GRE = Generic Routing Encapsulation

GRE creates a logical Tunnel between two routers. GRE itself doesn't encrypt; for Encryption, GRE over IPsec is normally used.

Example

R1 WAN = 10.0.0.1, R2 WAN = 10.0.0.2, and the Tunnel IPs are 172.16.1.1 and 172.16.1.2.

R1

conf t

interface tunnel 0
 ip address 172.16.1.1 255.255.255.252
 tunnel source 10.0.0.1
 tunnel destination 10.0.0.2
 no shutdown

R2

conf t

interface tunnel 0
 ip address 172.16.1.2 255.255.255.252
 tunnel source 10.0.0.2
 tunnel destination 10.0.0.1
 no shutdown

Test:

ping 172.16.1.2

Running OSPF over GRE

router ospf 1
 network 172.16.1.0 0.0.0.3 area 0

Verification

show interface tunnel 0
show ip interface brief
Memory aid: GRE = Tunnel | IPsec = Encryption
Part 6 — Security

22. Port Security

Port Security is enabled on Access ports so that only allowed MAC addresses can use the port.

Enabling

interface fa0/1
 switchport mode access
 switchport port-security

Maximum number of MACs

switchport port-security maximum 1

Static MAC

switchport port-security mac-address aaaa.bbbb.cccc

Sticky MAC

switchport port-security mac-address sticky

Violation Mode

ModeBehavior
ShutdownErr-disables the port
RestrictDrops traffic from unauthorized MACs and logs the Violation
ProtectDrops traffic from unauthorized MACs

Full example:

interface fa0/1
 switchport mode access
 switchport port-security
 switchport port-security maximum 1
 switchport port-security mac-address sticky
 switchport port-security violation shutdown

Verification

show port-security
show port-security interface fa0/1
show port-security address
Memory aid: Access Port → Maximum MAC → Allowed MAC → Violation

23. Layer 2 Security (DHCP Snooping and DAI)

These mechanisms on the switch block DHCP-based and ARP-based attacks.

DHCP Snooping

ip dhcp snooping
ip dhcp snooping vlan 10
interface g0/1
 ip dhcp snooping trust

Only a Trusted port (server side/Uplink) may send Offer and Ack; this stops a Rogue DHCP Server and builds the Binding Table.

Dynamic ARP Inspection

ip arp inspection vlan 10
interface g0/1
 ip arp inspection trust

DAI compares ARP messages against the Binding Table and stops ARP Spoofing.

show ip dhcp snooping binding
show ip arp inspection
